## Core Principles
- **Simplicity First**: Minimal impact. Touch only what's asked.
- **No Laziness**: Find root causes. No temporary fixes. Senior standards.
- **Surface uncertainty early**: Confused? Say so before proceeding.
- **Scope discipline**: No "cleanup" of unrelated code without approval.
- **Elegance check**: For non-trivial changes, ask "is there a more elegant way?"
- **Dead code**: After refactoring, list unused code and ask before deleting.
- **Push back**: If the approach has clear problems, say so with alternatives.

## Workflow
- For tasks 3+ steps or touching 3+ files: emit a brief plan and wait for redirect.
- Never mark complete without proving it works (tests, logs, or demo).
- After any correction: update `tasks/lessons.md` with the pattern.
- Use subagents to keep main context clean. One task per subagent.

## Task Tracking
- Plans → `tasks/todo.md`. Mark items complete as you go.
- Lessons → `tasks/lessons.md`. Review at session start.
